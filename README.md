# Research Credit Academy

Training demo for new R&D tax credit associates. Module 1 covers the four-part test under IRC section 41(d) / Treas. Reg. section 1.41-4.

> Educational demo only. Not legal, tax, or accounting advice.

## Stack

- Next.js (App Router)
- TypeScript
- Tailwind CSS

Content lives in local TypeScript modules under src/content/ for easy expansion.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000

```bash
npm run build
npm start
```

## Features (Module 1)

1. Home / curriculum — Module 1 available; Modules 2-4 Coming soon (QREs, Funded Research, Documentation & Interviews)
2. Lesson — Permitted purpose, technological in nature, elimination of uncertainty, process of experimentation
3. Quiz — Multiple-choice with immediate feedback, rationales, score, and retry
4. Case study — Fact pattern + structured questions with model answers after submit
5. Mock interview — Chat with a scripted busy engineer; End Session to four-part coverage scorecard

## Routes

- / — Curriculum overview
- /module-1 — Four-part test lesson
- /module-1/quiz — Knowledge check
- /module-1/case-study — Apex Motion Controls case
- /module-1/interview — Mock SME interview
